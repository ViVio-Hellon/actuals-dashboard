## 構成

```
actuals/
  vba_compat.py   Val・Format の四捨五入・Variant の比較・Excel 貼付けの型変換
  columns.py      RNE の列名（位置ではなく名前で読む）
  conditions.py   条件表（15 行）・入力チェック・初期値（受領ブックの設定シート）
  engine.py       ロットごとの計算（計算単重・枚数・直・集計日）とグループ判定（判定の経過つき）
  aggregate.py    月集計・年集計・明細・直別・HIT 数
  charts.py       グラフの描画計画（座標はサーバ、画面は描くだけ）
  sharedfile.py   共有 SQLite の読み書き（ロックファイル・差し替え・控え・届かない時）
  stores.py       条件表・手動訂正・変更履歴／蓄積した実績・取り込みの記録
  source.py       取り込み元（RNEConverter の SQLite・xls・貼付け）
  rne_runner.py   RNEConverter の呼び出し
  service.py      画面のための処理（ビューモデル）
  web/server.py   http.server（トークン・二重起動・放置時の終了）
  web/static/     画面（python-web-tools の CSS・部品を写したもの + このツールの部分）
  vendor/xls_reader.py   RNEConverter の xls 読取をそのまま写したもの
  xlsm.py         旧ブックの読み取り（移行・照合）
tools/compare_with_vba.py  並行運用の突き合わせ
tools/make_golden.py       正解データの作成
```
