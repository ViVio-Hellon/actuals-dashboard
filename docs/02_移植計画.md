## 既存基盤の調査結果

- python-web-tools（梱包資材総合ツール 4.8.123）は Flask + waitress（pip）。業務ロジック層 `packaging_tool/` は標準ライブラリだけ。
  倉入・実績集計・現場暦・直・グラフ・SymNavi を扱う機能は無く、重複はない。
- RNEConverter は標準ライブラリだけで SymNavi 抽出 → SQLite 配布を行う。RNE の追加は `config/rne_list.json` に 1 行。

流用するもの:

| もの | 出どころ |
|---|---|
| SymNavi 抽出一式（RNE 実行・認証・ログ） | RNEConverter |
| http.server の土台（トークン・待機画面・二重起動・自動終了・再接続） | RNEConverter `app/web/` |
| 共有 SQLite を写して読む（`source_db.py`）、ロック時の再試行（`sqlite_toolkit.py`） | python-web-tools |
| tokens.css / components.css / toast.js / askbox.js / api.js、SVG 描画の考え方 | python-web-tools |
| ログの決まり、エラー応答の形、`config/app.json`（ランチャー対応） | 両方 |
| CSV 書き出し（utf-8-sig、先頭ゼロ保護）、印刷 CSS | python-web-tools |

## 方針（Q1 を独立ツールとした場合）

```
Python（標準ライブラリだけ）
  ├─ http.server ── ブラウザ画面（127.0.0.1、起動トークン）
  ├─ sqlite3 ────── 倉入実績.sqlite3 を手元に写して読む
  │                 条件マスタ・手動訂正（共有に 1 つ、差し替え保存）
  ├─ csv ────────── 集計・明細を指定フォルダへ書き出し（ダウンロードしない）
  ├─ logging ────── ツール ID フォルダ・操作番号・エラー番号
  └─ subprocess ─── RNEConverter（--run --only KURAIRE）── SymNavi
（Access を使わないので cscript・ADODB・ACE は不要）
```

- 判定・計算・集計・並び順は VBA と同じ結果。結果が変わる変更は回答後
- 列は RNE の列名で対応付け、必要列が無ければ取り込み時に止める
- VBA 互換部品（Val、Format の四捨五入、Variant 比較、Excel 貼付け相当の型変換）を 1 か所に集めてテスト
- 正解データ: 受領ブックの 987 件（修正・月集計・ｸﾞﾗﾌ）。全件一致を自動テストで固定
- 並行運用期間に VBA 処理済みブックと突き合わせる照合ツールを用意
