# 倉入実績集計 現行VBA解析

対象: `【...】160901_IDPASS【...】.xlsm`（ファイル名の日本語部分は受領時に欠落）
VBA ソース: `docs/vba_source/`（UserForm01 の ID・パスワードは伏せ字に置換済み）

このドキュメントは実装前の解析結果です。移植方針・確認事項・画面案は `docs/02_移植計画.md` を参照。

## 1. このVBAは何をしているシステムか

梱包ライン別の倉入実績ダッシュボード。

1. SymNavi で RNE を実行し、倉入実績（ロット単位）を DATA シートに取り込む
2. 設定シートの条件で、各ロットを 15 グループ（丸徳ﾗｲﾝ、L-1、SVC、LVC、HVC など）に振り分ける
3. 計算単重・倉入枚数・直・集計日を計算する
4. グループ×日（月集計）、日×グループ（年集計）、選んだグループの日別・直別（ｸﾞﾗﾌ）に重量と枚数を集計する

## 5. 判定ロジックと計算（業務ルール）

### ロットごとの計算

| 項目 | 式 |
|---|---|
| 計算単重 | `Format(Val(製造板厚)*Val(製造板幅)*Val(製造板丈)*Val(比重)/10^6, "0.00")` |
| 倉入枚数 | 計算単重 ≠ 0 のとき `Format(Val(実績_倉入重量)/Val(計算単重), "0")` |
| 直（現場暦のみ） | AH 列の時: 7〜14 → 1、15〜22 → 2、他 → 3。太陽暦では計算しない（空） |
| 集計日 | 現場暦 = AH（BOX実績_作業終了_日付）、太陽暦 = V（最小の倉入完了_年月日） |
| 並べ替え | AF 降順・V 昇順の設定を書いているが `.Apply` が無く、**実際には並べ替えていない**（DATA は SymNavi の出力順のまま。実装時に保存値との照合で判明） |
| 集計月の既定 | DATA 先頭行の AF の年月（暦によらず） |

### グループ判定（設定 5〜19 行を上から）

n = 0（製造）／5（ｵｰﾀﾞｰ）。通常条件は E3、NOT 条件は O3 で決める。

1. NOT 使用（N 列 `*`）の行で、`Val(列 12-n)`（※調質列）・板厚・板幅・板丈（MIN≦、MIN＜、≦MAX）・計算単重 ≦MAX がすべて当たれば `Exit For`（判定終了。それまでの結果は残る）
2. 板（形状 ≠ 30 または製造板丈 > 0）で、材質（列 11-n と完全一致）・板厚・板幅・板丈・計算単重が当たれば、最初の 1 回だけグループ = 行番号 − 4
3. 実績設備コースに `LS4 VC` があり、36 列目 = `B535` かつ 37 列目が空 → 同時VC `L`。`FS4 VC` で `SPV2001` / `AL-200` → `F`
4. 同時VC でなく、D 列が `*`（VC 行）で、VC が 1 または `"01"` → その行で確定して `Exit For`

`*` は条件なし。空欄は Variant の比較で 0（数値と比べる時）または ""（文字と比べる時）。

### 集計

- 月集計: 修正!C（集計用）= グループ、E = 年(D2)、F = 月(D2)、G = 日 の SUMIFS（重量 = 修正!T、枚数 = 修正!I）
- 年集計: 修正!C = グループ、D = 日付 の SUMIFS。見出し（4 行目）が空の列は空表示
- ｸﾞﾗﾌ明細: 集計用 ≠ 0、選んだグループ（または ALL）、形状 = 10、月 = 月集計 D2 の月（年は見ない）
- ｸﾞﾗﾌ直別: 明細を日・直で SUMIFS。合計（H/I 列）は月集計の行を参照（ALL は総計行）

## 7. エラー処理

- `On Error Resume Next` は AppActivate の 1 か所だけ
- DDE 命令の成否を確認しない。SymNavi が失敗すると Workbooks.Open / Kill でエラー停止
- 途中停止時に ScreenUpdating・Calculation が戻らない

## 8. 現行の問題点（不具合候補）

| # | 内容 | 結果への影響 |
|---|---|---|
| 1 | NOT 条件の材質が `Val(調質)` と比較される（列ずれの疑い） | あり（現データでは L-1 の NOT が常に不成立） |
| 2 | 同時VC が参照する 36・37 列目（表VC・裏VC）が現行 RNE に無い | 同時VC は常に不成立 |
| 3 | 修正!A の手動訂正が行位置で保持される。データ再取得で別ロットにずれる | あり（運用次第） |
| 4 | 年集計の日付が 2015 年度固定、見出しが旧グループ名 12 個 | 年集計は現状すべて 0 |
| 5 | ｸﾞﾗﾌ明細の月絞り込みに年が無い | 複数年データの時のみ |
| 6 | チェックツールの判定手順が本処理と異なる（NOT 材質、NOT 時の扱い、VC 行、形状） | 表示のみ |
